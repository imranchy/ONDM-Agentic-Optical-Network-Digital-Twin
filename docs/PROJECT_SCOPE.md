# Project scope and provenance

**Research:** agentic VLM interpretation of optical network diagrams, with grounded graph computation and future simulation/inventory verification.

**Monday 16 Nov 2026 prototype:** local image-capable VLM, Streamlit UI, three scenarios (route provisioning, link-failure impact, inventory-aware query) using the corrected synthetic pilot. Formal evaluation is deferred.

**Post-demo research:** physics-aware GNPy path simulation, real NetBox adapter and sync safeguards, topology-aware data split design, TopoBench suitability study, and transparent measured VLM evaluation.

**Data provenance:** synthetic generator output, not live operator telemetry or field-validated optical equipment. Earlier 500-graph dataset is archived historical evidence, not the authoritative pilot.

**Open items:** equipment fidelity, separate amplifier/transceiver symbols, proof of family-grouped leakage-free splits, complete simulator environment validation and licensing.
